## Sobre mim

Sou estudante de **Análise e Desenvolvimento de Sistemas (ADS)** na **Unisa**, em São Paulo, com foco profissional em **Análise de Dados**.

Tenho formação técnica em **Informática** e certificação em **Git e GitHub pela FGV Online**. Atualmente, venho aprofundando meus conhecimentos em **Python, SQL e Excel**, desenvolvendo projetos práticos e construindo uma base sólida para atuar na área de dados.

Meu objetivo é utilizar dados de forma estruturada para gerar análises mais claras, identificar padrões e transformar informação em suporte para decisões.
